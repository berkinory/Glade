# Cua Driver Node runtime (MPL-2.0)

The `@trycua/cua-driver` native package ships `cua_driver_node_runtime.node`, a build derived from the N-API runtime in `uniffi-bindgen-react-native` 0.31.0-3, and depends on the `@ubjs/core` and `@ubjs/node` packages. Source code:

- The runtime's source and build script are in the Cua repository at the matching release tag: https://github.com/trycua/cua/tree/cua-driver-rs-v0.34.0
- `@ubjs/core` and `@ubjs/node` 0.31.0-3 are published on npm with their source.
