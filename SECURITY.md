# Security policy

## Supported versions

Security fixes are prioritized for the current `main` branch and the latest
publicly released version when one is available. Older versions may not receive
fixes.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/berkinory/Glade/security/advisories/new)
to contact the maintainers. Please do not open a public issue or pull request
for a suspected vulnerability.

Include the affected version or commit, operating system, expected impact, and
steps to reproduce. Share only the minimum logs or files needed to investigate,
and remove credentials and personal data. Test only on systems and accounts you
own or are authorized to use.

We will review the report privately, coordinate a fix, and discuss disclosure
with the reporter before publishing details. Vulnerabilities in Glade's local
server, update flow, provider credentials, or computer-use permissions are in
scope, even when the affected code originated upstream.
